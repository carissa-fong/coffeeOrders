# coffeeOrders
## Coffee Sales Dashboard

This project analyses a sample cafe dataset containing coffee orders, product information, and customer data. Using Excel, I applied PivotTables and other data analysis tools to examine sales performance across different categories, identify the top five customers by total sales, and uncover key sales trends.

The analysis was consolidated into an interactive dashboard that provides a clear overview of overall coffee sales and allows users to explore important business insights efficiently.

**Tools used:** Microsoft Excel, PivotTables, Charts, Slicers, Data Analysis
